# Офіційні документи: українська мова, 7 клас

Сюди кладемо **дослівні копії** офіційних документів МОН, на яких тримається зміст Лесі й карта навчання. Їх не переписуємо й не переказуємо: транскрипції (`.md`) — дослівні, з позначкою, звідки взято.

## Стан

**Завантажено** (2026-10-14): модельна навчальна програма «Українська мова. 7–9 класи» (автори Заболотний О. В., Заболотний В. В., Лавринчук В. П., Плівачук К. В., Попова Т. Д.). Це одна з двох рекомендованих МОН модельних програм для 7–9 класів; набір орієнтується на неї. Якщо школа учня вчить за іншою (Голуб Н. Б., Горошкіна О. М.), теми 7 класу подібні, але порядок може відрізнятися — Леся йде за тим, що зараз у школі.

Правила правопису — за чинним «Українським правописом» (2019).
