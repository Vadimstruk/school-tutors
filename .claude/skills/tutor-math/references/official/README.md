# Офіційні документи: математика, 7 клас

Сюди кладемо **дослівні копії** офіційних документів МОН, на яких тримається зміст Олі й карта навчання. Їх не переписуємо й не переказуємо: якщо потрібна транскрипція (`.md`), вона дослівна, з позначкою, звідки взято.

## Стан

**Документів ще немає.** Поки їх немає, Оля пояснює стандартну шкільну математику 7 класу за підручниками й чесно каже, що звірки з програмою ще не було. Карта навчання для математики не наповнюється, доки немає програми.

## Що потрібно

З 2024/2025 навчального року 7 клас навчається за Державним стандартом базової середньої освіти (НУШ). Для математики МОН рекомендує кілька **модельних навчальних програм** для 7–9 класів; школа обирає одну з них. Серед знайдених (реквізити наказів ще треба звірити з першоджерелом на mon.gov.ua):

- «Алгебра. 7–9 класи» і «Геометрія. 7–9 класи» (автор Істер О. С.) — окремі курси алгебри й геометрії;
- «Математика. 7–9 класи» (Василишин М. С., Миляник А. І. та ін.) — інтегрований курс.

Набір орієнтується на **окремі курси алгебри й геометрії** (карта має дві вкладки). Якщо школа учня вчить інтегрований курс, теми ті самі, але порядок інший — Оля все одно йде за тим, що зараз у школі.

Для кожного документа покласти сюди:

- PDF з офіційного джерела (mon.gov.ua або imzo.gov.ua);
- дослівну транскрипцію в `.md` (для пошуку й посилань);
- у цьому файлі — назву, автора, номер і дату наказу МОН, посилання, дату завантаження.
