# Карта навчання

Одна сторінка, де учень бачить свої предмети, теми й короткі уроки, а батьки — як ідуть справи.

- `map-template.html` — сама сторінка (вигляд і логіка). Рядок `/*@@CONTENT@@*/` — місце, куди збирач вставляє уроки.
- `content/` — уроки. Лише з офіційної програми: нічого не вигадуємо.
- `build-map.py` — перевіряє уроки й збирає готову сторінку `study-map.html` (її можна відкрити подвійним кліком у браузері).

## Як влаштовано зміст

`content/subjects.json` — перелік предметів:

```json
{"subjects": [
  {"id": "algebra", "name": "Алгебра", "grade": 7, "tutor": "Оля", "tutorCall": "Олю", "icon": "➗",
   "files": ["algebra/s1.json", "algebra/s2.json"]}
]}
```

`tutorCall` — ім'я в кличному відмінку (для запиту «Олю, дай мені задачі…»). `files` — файли розділів, по одному на розділ, у тому порядку, як їх показати.

Файл розділу: розділ → теми → підтеми.

```json
{"id": "A1", "subject": "algebra", "name": "…", "what": "…",
 "topics": [{"id": "A1.2", "name": "…", "what": "…",
   "subtopics": [{"id": "A1.2.3", "name": "…", "status": "ready",
     "programmeRef": "дослівна фраза з програми",
     "lesson": {"what": "1–3 речення простими словами",
                "ideas": ["…"],
                "rules": [{"f": "a(b + c) = ab + ac", "means": "…"}],
                "example": {"task": "…", "steps": [{"do": "…", "why": "…"}], "answer": "…"},
                "mistakes": ["…"],
                "check": [{"q": "…", "a": "…"}]}}]}]}
```

Правила, які перевіряє збирач:

- ID ієрархічні й унікальні в усіх предметах: розділ `A1` → тема `A1.2` → підтема `A1.2.3`.
- `status`: `"ready"` (урок є) або `"planned"` (на карті — «урок готується»). `lesson` обов'язковий лише для `"ready"`.
- `programmeRef` обов'язковий для кожної підтеми — дослівна фраза з офіційної програми.
- `rules` може бути порожнім; `ideas`, `example.steps`, `mistakes`, `check` — ні.
- У текстах можна лише теги `<b>`, `<i>`, `<sub>`, `<sup>`.
- `subject` у файлі розділу має збігатися з `id` предмета, що його називає.

## Як зібрати

```
python study-map/build-map.py            # перевірити й зібрати study-map/study-map.html
python study-map/build-map.py --check    # лише перевірити
python study-map/build-map.py --content ІНША_ТЕКА   # зібрати з іншої теки (для тестів)
```

Помилки схеми зупиняють збірку (код виходу 1), попередження — ні. Поки предметів немає, сторінка показує «Карта ще наповнюється…».

## Версія карти

Змінив сторінку чи уроки — **підніми `MAP_VERSION`** у `map-template.html` (формат `РРРР-ММ-ДДx`, напр. `2026-10-14b`) і перебудуй. За цією версією репетитор бачить, що опубліковану копію учня треба оновити.

Особиста копія учня для публікації: `python shared/scripts/build-map-artifact.py <корінь-проєкту> <slug-учня>` → `_memory/learners/<slug>/map/study-map.html`.
