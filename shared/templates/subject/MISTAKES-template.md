# Типові помилки: {subject}

_Один запис — один повторюваний патерн, а не одна помилка. Розрізняй два типи: **не знає правила** (прогалина в знаннях) і **знає, але не застосував** (неуважність: знак, переписування, обчислення). Їх лікують по-різному._

_Помилку вважаємо подоланою, лише коли учень розв'язав правильно сам, з першої спроби, після перерви (не в той самий день, що пояснення). Не видаляй подолані записи — познач дату._

## Активні

### Шаблон запису

```markdown
### {Коротка назва — напр., «Мінус перед дужкою»}
- **Що відбувається:** {одне речення, по можливості словами учня}
- **Як правильно:** {правило}
- **Тип:** не знає правила / знає, але не застосував
- **Підтема:** {ID}
- **Де трапилося:** {ID задач і дати}
- **Скільки разів:** {N}
- **Подолано:** ні / так (дата)
```
